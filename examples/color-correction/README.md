# 最小独立示例

运行 `npm run example:color`。示例直接导入公共色彩模块、Three.js 和 r169 USDZExporter；不加载 App、viewer、色卡识别、FFmpeg 或 localStorage。

生成的色块与渐变分别烘成未补偿和补偿纹理。选择三份实测档之一，下载两份 USDZ，使用相同 App、姿态和光照条件比较。卡片是矩形六面简化模型；棱柱只含六个侧面（无端盖）。它们用于演示接入，不代表与原实测几何/周围面完全相同，也不能作为标定色卡。重新标定请复用主应用的完整导出流程。

`baseline.json` 保存原 `c947ee4` 算法在三份档/七个输入上的数值输出；forward 是预测不是实拍。`npm run test:color:standalone` 自动对照该基线，并在没有主应用的临时目录验证成品包。

公开对照证据若需添加照片，应使用自己生成/有授权的素材，记录 App/OS 版本、材质、补光和截图方法；不要把这些网页截图冒充 Apple 实拍。
